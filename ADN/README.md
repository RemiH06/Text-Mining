# Sequence Alignment Using Edit Distance Algorithms

Lab #1 (NLP course) — from-scratch **Needleman-Wunsch** (global) and
**Smith-Waterman** (local) DNA sequence alignment, applied to the 10 DNA
pairs supplied in `NLP_O26-Sequence_Alignment_Assignment_v1.pdf`.

├── Sequence_Alignment.ipynb     # Main notebook — run/present the whole lab from here

## Running the code

**Batch run (regenerates everything in `results/`):**

```bash
python alignment.py
```

This aligns all 10 pairs with both algorithms (match=+2, mismatch=-1,
gap=-2), writes `results/scores_summary.csv` and `results/alignments.txt`,
saves two example score-matrix heatmaps to `results/figures/`, runs the
parameter-sensitivity study (Part 3) into
`results/parameter_sensitivity.csv`, and — if `biopython` is installed —
the bonus Biopython comparison into `results/biopython_comparison.csv`.

**Notebook (used for the in-class presentation):**

```bash
jupyter notebook Sequence_Alignment.ipynb
```

The notebook imports `alignment.py` and `sequences.py` directly and walks
through: the algorithms, matrix heatmaps with the traceback path overlaid,
aligned sequences for all 10 pairs with matches/mismatches marked, the
parameter-sensitivity analysis, and the Biopython comparison.

## Scoring

Default scheme required by the assignment:

| Match | Mismatch | Gap |
|-------|----------|-----|
| +2    | -1       | -2  |

`needleman_wunsch()` / `smith_waterman()` in `alignment.py` accept
`match`, `mismatch`, and `gap` as keyword arguments for experimenting with
other schemes (see `PARAMETER_SETS` in `alignment.py` for the ones used in
the Part 3 sensitivity study).

## Validation

Every alignment score produced by our implementations matches Biopython's
`Bio.Align.PairwiseAligner` exactly on all 10 pairs, in both global and
local mode (see `results/biopython_comparison.csv`).

## Extra: are these sequences real human DNA?

The 10 pairs from the assignment PDF are synthetic (built for the
exercise), not verified fragments of a real genome. `genome_search.py`
checks this directly: it downloads (and caches under `data/`) the human
mitochondrial reference genome (NCBI accession `NC_012920.1`, ~16.5 kbp —
the same reference the assignment PDF itself suggests), then runs our own
`smith_waterman()` for all 20 sequences (10 pairs x seq1/seq2) against
both strands of it.

```bash
python genome_search.py
```

Requires internet access on first run (to fetch the reference genome);
later runs reuse the cached copy in `data/`. Result: **0 / 20** sequences
are genuine matches — every best hit stays around 35–40% of the maximum
possible score, well under the 90%-score / 90%-coverage bar used to call
something a real match, which is what you'd expect from short random-ish
queries against any ~16.5 kbp reference by chance. See
`results/human_genome_search.csv` and Section 9 of the notebook for the
full breakdown and a plot of every sequence's score vs. coverage.
